# Merchant AI Teammate

A polished hackathon demo for an autonomous merchant business partner.

## Demo flow

Analyze → Detect → Recommend → Approve → Execute → Report

The frontend uses mock merchant data, so it can be deployed directly to Vercel without a backend or environment variables.

## Vercel

- Root Directory: `frontend`
- Framework: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

## Local development

```bash
cd frontend
npm install
npm run dev
```

This is a demo prototype. The campaign execution is simulated in the browser and does not execute real transactions.
